In this hands-on workshop, you’ll learn how to move beyond single-agent demos and build scalable, production-ready AI systems using Solace Agent Mesh and event-driven architecture.

We’ll start by unpacking the challenges of orchestrating autonomous agents at scale - from brittle prompt chains to opaque control flows. Then, through guided exercises, you’ll design and deploy a multi-agent system where agents communicate, coordinate, and complete tasks via event-based MCP and A2A interactions.

Whether you’re a developer, architect, or AI enthusiast, this workshop will give you practical tools and architectural patterns to build intelligent systems that are not just smart - but coordinated, observable, and ready for production.

**Key Takeaways:**
* Understand how Solace Agent Mesh provides structured, governed agent coordination
* Leverage Solace Topics for Intent-Based Routing and events to create loosely coupled agent workflows
* Model MCP and A2A Communication Using Events
* Design Resilient Multi-Agent Workflows
* Deploy and Connect Agents via Solace Agent Mesh
* Track and Observe Agent Interactions in Real Time
